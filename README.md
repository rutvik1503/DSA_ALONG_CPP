# DSA_ALONG_CPP 🚀

Welcome to the **DSA_ALONG_CPP** repository! This collection of C++ programs is a journey through Data Structures and Algorithms (DSA). Each folder corresponds to a specific day of learning, filled with examples that showcase key programming concepts, including basic syntax, loops, data types, and user input.

Whether you're a beginner looking to dive into C++ or you're refining your DSA skills, this repository will guide you step-by-step through essential concepts.

---

## 📅 Day 01 : Getting Started

### 📝 Files:

#### **`demo.cpp`**
A simple introduction to C++ syntax and fundamental programming concepts. This program sets the stage for your journey, covering basic input/output and simple logic.

---

## 📅 Day 02 : Printing Some Messages

### 📝 Files:

#### **`Desimal_Num.cpp`**
This file contains a simple C++ program that demonstrates basic output operations using the cout stream. The program prints a blank line, the number 1, the result of the arithmetic operation 2 + 2 (which equals 4), and additional blank lines. This program is a minimal example of using cout for printing values and expressions to the console.

---

## 📅 Day 03 : Creativity With Some Arithmatic Operators

### 📝 Files:

#### **`Arithmatic_Operators.cpp`**
This file contains a simple program demonstrating basic arithmetic operations in C++. From addition to modulus, the program performs essential calculations with integer variables `a` and `b`, and prints results clearly.

#### **`Charactor_Array.cpp`**
A fun exploration of string handling in C++. This program prints a string using a character array (`"Rutvik"`) and shows how to access and display individual characters from the string both as a whole and vertically.

#### **`Data_Type.cpp`**
Learn about C++'s powerful data types! This program covers integers, floats, characters, and strings, printing each variable's value and showing how different types can be used in your programs.

#### **`For_Loop.cpp`**
A classic example of using a `for` loop in C++. This program prints the numbers 1 through 10 using a `for` loop and illustrates how loops are essential for repetitive tasks.

#### **`Multiplication_Table.cpp`**
Got a multiplication table in mind? This program generates a multiplication table for the number `a`, iterating from 1 to 10 and displaying the results in a user-friendly format.

---

## 📅 Day 04 : Getting Input From The User

### 📝 Files:

#### **`Input_From_User.cpp`**
Dive deeper into user interaction! This program prompts the user for two integer values and performs basic arithmetic operations on them, including addition, subtraction, multiplication, division, and modulus. Perfect for practicing input validation and arithmetic operations in C++.

- **Control Structures**: Mastering loops and understanding how to repeat operations efficiently.
- **Data Handling**: Using variables, arrays, and different data types to manipulate and store information.
- **User Interaction**: Taking input from users and making your programs interactive.
